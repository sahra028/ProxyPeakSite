FAQ

Is a Telegram proxy a VPN?

No. It only routes Telegram traffic, not your whole phone. The server owner can see your IP address.

What is an MTProto proxy?

MTProto is Telegram’s own protocol. An MTProto proxy relays your Telegram connection through another server, using a server address, a port and a secret key.

How do I add a Telegram proxy manually?

Open Telegram, go to Settings, then Data and Storage, then Proxy Settings, tap Add Proxy and choose MTProto. Enter the server, port and secret. Menu names vary a little between app versions. The easier way is to tap Connect on this page.

What does server location mean?

The country where the proxy server’s IP address is registered. If the proxy uses a relay, the final route may differ.

Which country should I choose?

There is no single best country. Results depend on your network and provider, so try a few countries and prefer the newest proxies with the most ❤ votes. Closer servers often have lower latency, but not always.
